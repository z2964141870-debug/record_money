# 版本变化

## v0.6.0：无模型记账与可选AI

- 固定格式不需要模型，支持支出、收入、退款、修改、撤销、账单与三种图表。
- 自然语言可选Responses或Chat Completions，默认关闭思考，已有模型与推理设置保留。
- 文字、结构化和图片能力分别验证；文字模型也能保存，网络和权限错误不误判为不支持图片。
- 缩小模型上下文，保留本地记忆与图片核对；含糊退款和未知贷款日期追问。
- 保留Mac、Linux、Windows安装、备份和升级支持。

## v0.5.0：Windows安装包

- Windows 10 22H2/11 x64解压后双击EXE，内置运行环境，无需Node、Docker或管理员权限。
- 自动创建桌面快捷方式、登录自启；托盘菜单可打开账本、停止服务和关闭自启。
- 自选账本目录，升级前备份，保留配置、账目和聊天；启动失败回到原服务。
- Windows原生构建数据库及图表依赖，使用系统中文字体，GitHub自动构建和验收安装包。

## v0.4.1：钉钉读图与安装说明

- 钉钉新增收支与退款正确保存消息渠道来源；未绑定和绑定失败提示改用通用机器人文案。
- 修复钉钉返回HTTP阿里云图片地址时下载失败的问题，改用HTTPS下载。
- 实际验证文字、连续对话、图表、提醒和图片识别；图片先核对，确认后入账。
- 缩短首页和安装说明，Release直接链接飞书、钉钉创建教程及权限清单。
- 64项测试及生产构建通过。

## v0.4.0：首次安装与聊天渠道

- 浏览器首次配置支持选择飞书/钉钉，单次提交检查应用凭证、文字和图片模型接口，保存后自动重新启动；未配置时不运行定时账单。
- 新增Mac预构建应用包，内置运行环境与生产依赖，双击后自动安装后台服务并打开浏览器，升级前备份并保留独立数据；当前尚未Apple公证。
- Linux使用预构建GHCR镜像，首次启动自动准备目录，Compose不再要求用户构建或运行终端向导。
- GitHub版本标签触发自动测试、两种Mac安装包、两个Linux架构镜像及Release附件发布。
- 钉钉采用官方Stream SDK，适配单聊文字/图片、主动提醒、账单与图表发送，完成模拟接口验收，尚待实际应用联调。

## v0.3.1：网页更换模型服务

- 网页模型服务支持修改Base URL、API Key、模型和推理强度，持久保存后下一次调用生效，无需重启。
- 支持测试尚未保存的文字及图片接口，使用虚构样例，不写入账本或更改飞书配置。
- API Key留空保留已有值，不向网页回传；更换服务域名或端口时要求填写新密钥。
- 更换服务保留本地会话、账目和资金资料，新增回归测试验证下一次请求使用新配置并带上双方历史对话。

## v0.3：可分发版本

- 新增交互式配置向导：指定存储位置、飞书与模型凭证、模型和推理参数，密钥不回显，配置权限600。
- 新增飞书凭证、Responses文字与示例图片连接检查，测试不写入账本。
- 新增Docker Compose部署、中文字体、持久挂载、本机端口映射及健康检查。
- 新增白名单源码ZIP和SHA256清单、MIT许可证、安装与升级文档、模型兼容验收说明。
- 新安装不预设模型品牌，推理默认关闭；已有设置不变。Mac后台更新保留已有存储位置与配置，运行目录包含管理脚本所需源码。

## v0.2 图片清单改进：2026-10-06

- 收图直接从原图提取结构化交易块，保留时间和商户对应关系；同次调用保留文字识别，汇总与裁切行独立排除。
- 新增持久图片清单和连续核对操作，支持补年份/账户、逐行修正/保留/跳过、取消；程序计算整数分合计，信息齐全后生成方案，确认才事务入账。
- 疑似重复及已有相似账目必须核对，图片内容哈希拦截同图重发；未知金额/日期/账户/币种不猜。退款关联原支出，转账明确两个账户。
- 模型调用增加JSON对象输出约束；支持规范化R行号与展示原始汇总金额的货币格式，汇总不参与入账。

## 2026-10-06：v0.2

- 飞书图片与网页图片上传：现有Responses模型提取文字，先展示识别结果，图片入账需确认，永久标记同一图片的导入状态。
- 根据真实账本生成账单、支出饼图、资金分布PNG，网页下载或飞书发送，无模型生图费用，分类负值和未知余额单独标明。
- 左侧新增物品清单，登记购入价、购买日、停用日和备注，计算已用天数与每日使用成本，支持归档恢复，不重复记支出。
- 左侧新增贷款与借款，整合助学贷款、月付、亲友借款，与原负债余额同步；支持新增本金、还款本金/利息分离、合同分期和固定月付预览。
- 新增物品/贷款/分期审计和借还记录，操作README覆盖新增模块；数据库备份同时保存图片附件，图表快照可重新绘制。
- 沿用Mac运行方式，hp3090迁移仍暂停。本人已确认开通新增飞书资源及消息读取权限，正式机器人图表上传与发送、图片下载与OCR回执均已实际验证。
- 修正飞书图片下载权限错误被误报为模型不可用的问题；明确下载消息图片还需im:message:readonly，权限不足时保留原消息供开通后重试。

## 2026-10-06：连续对话与主动提醒

- 模型读取同一会话最近20轮用户文字及实际回复，支持接续备注、纠正和确认；已发送的主动账单/提醒也可作为紧随其后回复的上下文。
- 明确的待确认方案保存24小时，支持短句确认、取消、重启后续接、执行去重及账本变化时拒绝覆盖。
- 默认20:00提醒当天尚无收支的用户，每天最多一次；支持网页修改、当天豁免和发送前取消过时提醒。
- 自动生成本地每日操作README，个人数据不进入Git；项目说明按功能变化维护。
- 实测京东金融三持仓的连续对话，合计6090.65元，累计收益只存备注，无重复扣减。测试使用隔离的内存账本。
