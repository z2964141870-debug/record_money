# 创建飞书机器人

需要飞书组织管理员权限。没有组织时，可以先创建自己的组织。

## 创建应用

1. 登录 [飞书开发者后台](https://open.feishu.cn/app)，创建“企业自建应用”。
2. “添加应用能力”中添加“机器人”，填写名称和图标。
3. 在“凭证与基础信息”找到 **App ID、App Secret**，填到记账助手的配置页，再填模型服务信息，点击“连接并保存”。

## 开权限

在“权限管理”开通以下 **应用身份权限**：

| 权限代码 | 用途 |
| --- | --- |
| `im:message.p2p_msg:readonly` | 接收发给机器人的私聊消息 |
| `im:message:send_as_bot` | 发送回执、提醒和账单 |
| `im:resource` | 上传账单图表 |
| `im:message:readonly` | 下载你发来的图片 |

## 接收消息并发布

1. 保持记账助手运行。在“事件与回调”选择 **使用长连接接收事件**，添加 **接收消息**：`im.message.receive_v1`。
2. “版本管理与发布”创建版本，可用范围只选择自己，发布并完成管理员审批。权限修改后也要重新发布。
3. 在飞书搜索机器人，私聊发送“绑定账本”。回到记账助手网页“设置”，点击 **绑定此用户**。
4. 发 `奶茶20` 测试，确认收到回执且网页有记录。测试后可撤销。

找不到机器人：检查发布状态和可用范围。收不到消息：检查长连接事件和用户绑定。图片下载失败：检查 `im:message:readonly`；只开 `im:resource` 不够。
