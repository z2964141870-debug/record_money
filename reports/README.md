# 怎么用

先 [安装](DISTRIBUTION.md)，再按 [飞书](FEISHU.md) 或 [钉钉](DINGTALK.md) 教程创建机器人。在网页绑定自己后，就能私聊记账。

## 常用说法

| 发送内容 | 结果 |
| --- | --- |
| `CoCo奶茶20` | 支出20元，餐饮/饮料 |
| `妈妈红包30` | 收入30元 |
| `刚才那杯其实18` | 修改上一笔 |
| `早上那张12.8的券退款了` | 关联原支出，记录退款；多笔候选时询问 |
| `撤销 #3` | 撤销记录，保留历史 |
| `这个月饮料花了多少` | 查询分类明细 |
| `给我本月账单图片` | 返回账单图片 |
| `本月支出饼图`、`资金分布图` | 返回对应图表 |

## 发图片

发收据或账单截图，先收到待核对清单，**不会直接入账**。缺年份、账户等信息时补充，例如 `2026年，支付宝余额`。可以说 `跳过R2`、`R3改成0.80元`。

核对最终方案后回复 `确认入账`；只测试识别时回复 `取消图片`。汇总金额、余额和优惠不当作交易，疑似重复会提示核对。

## 账户、贷款、物品

- **资金账户**：`微信零钱现在有1000元，美团月付还欠300元`。余额校准不计为收支，月付欠款计为负债。
- **转账和还款**：`从支付宝余额还美团月付100元`。本金还款不重复计消费；需要说明两端账户。
- **锁定理财**：分别建立账户，填写金额和解锁日期。到期只提示待赎回，不自动转成现金。
- **贷款与借款**：填写欠款、债权人、开始还款日和月付计划。未知日期留空，不自动推算合同。
- **物品清单**：`手机3000元，2021年9月30日买的`。保存购入价与日期，计算使用天数和每天成本。

网页也能新增、修改、撤销记录和导出CSV。金额用人民币，日期按北京时间。

## 固定格式（无需AI）

| 输入 | 用途 |
| --- | --- |
| `支出 20 餐饮 奶茶` | 当天支出 |
| `收入 30 红包 妈妈红包` | 当天收入 |
| `退款 #123 12.8` | 关联原支出 |
| `修改 #123 金额 18` | 修改金额 |
| `撤销 #123` | 撤销，保留历史 |
| `今日账单` / `本月账单` | 查询 |
| `本月账单图` / `本月饼图` / `资金分布图` | 三种图表 |

可选字段放末尾：`支出 20 餐饮 奶茶 日期=2026-10-06 账户="支付宝 余额"`。账户需先在网页创建；不填账户就不关联账户、不改余额。格式错误不会入账。

固定模式也能在网页管理资金、贷款和物品、导出CSV及备份。上面的自然语言示例需要启用AI。

## 提醒和账单

当天没有收支，默认 **20:00** 提醒一次；回复 `今天没有收支` 可免去当天提醒。网页“设置”能改时间或关闭。

日报每天21:30，周报周日21:30，月报每月1日09:00。电脑必须在线。

## 设置和备份

网页“设置 → 模型服务”可换模式、接口、URL、API Key、模型和推理强度，对话记忆和账本保留。API Key留空保留原密钥，换服务域名时需填新密钥。配置细节见[模型说明](MODELS.md)。

数据在安装时选定的目录；每日自动备份，也能点“立即备份”。每天的操作记录保存在该目录的 `data/operations/日期/README.md`。更换模型时会把近期对话和账目发给所选服务，请使用自己信任的服务。

消息失败时，在“运行状态”查看和重试。没有收到回执时先核对网页。程序只管理账本，不连接金融平台或操作真实资金。
