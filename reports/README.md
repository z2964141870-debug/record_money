# 私人记账助手 v0.2

个人账本：飞书私聊文字/图片、本机网页、真实账本PNG图表、物品使用成本、贷款与借款、资金账户与负债分类、锁定理财、关联退款、日周月账单。账目以人民币整数分保存，统一使用北京时间。

## 目录

| 目录 | 内容 | Git |
| --- | --- | --- |
| `data` | 本机凭证、SQLite账本、备份、测试数据 | 仅保留目录，实际内容不提交 |
| `logs` | 后台标准输出、错误输出、运行记录 | 实际内容不提交 |
| `script` | 后端、网页、脚本、测试、配置模板 | 提交源代码和依赖锁文件 |
| `reports` | 使用说明、接入步骤、验证与版本记录 | 提交 |

## 启动

要求 Node.js 24 或更高版本。在 `script` 目录执行：

```sh
npm ci
npm run build
npm start
```

打开 <http://127.0.0.1:4317>。网页仅监听本机环回地址，不向局域网或公网开放。

如果端口被其他程序占用，修改 `data/config.env` 中的 `PORT`，重启后使用相应端口。代码或网页更新后需要重新构建并重启。

## 配置

首次使用将 `script/config.example.env` 中的字段填写到 `data/config.env`。该文件、实际账本、日志、备份均已被Git忽略，配置文件权限应为600。

模型通过 Responses API 调用。模型名称和推理强度可在网页“设置”中修改，下次调用立即生效；服务地址、API Key和飞书凭证在项目 `data/config.env` 中修改，再执行 `npm run service:install` 同步并重启。API Key及App Secret不显示在网页或日志中。

当前配置使用用户指定的HTTP模型服务。模型请求会发送当前文字、同一会话最近最多20轮用户消息和实际回执、最近最多60笔账目、资金账户、物品及贷款资料供语义理解；读图请求会发送所上传图片。账本和完整对话保存在本机。后续可直接改为HTTPS服务地址。

飞书应用设置见 [FEISHU.md](FEISHU.md)。在飞书私聊机器人发送一条测试消息后，到网页“设置”绑定待确认用户。绑定前的消息只用于识别待绑定用户，不会入账；绑定后仅处理该用户的新消息。

## 记账

- `CoCo奶茶20`：支出20元，餐饮/饮料。
- `收入，妈妈红包30`：收入30元，红包/家人红包。
- `买了张券12.8`：支出12.8元，用途不明时待分类。
- `早上那张12.8的券退款到账了`：匹配原支出并记录退款；多笔候选需要选择。
- `刚才奶茶实际18`、`撤销 #3`：修改或撤销，保留历史。
- `这个月饮料花了多少`：查询本月对应分类明细。
- 收到确认单后，回复 `选择 C1 #3`，或在网页“运行状态”选择对应记录。

网页支持手动新增、编辑、撤销、记录退款、查看修改历史、筛选和CSV导出。无法识别的金额或方向会询问；模型不可用时不会先把猜测写到账本。

退款必须关联支出，累计退款不能超过原消费；有退款的原支出需先撤销退款再撤销。普通收入与退款分开统计，账户内部转账不计为收入或消费。跨期退款按到账日期统计本期现金流，原交易最终净支出也会保留。

## 资金账户

网页“资金账户”分为现金余额、投资理财、锁定资金、月付欠款。预建微信零钱、支付宝余额、京东小金库、LGB基金、抖音月付、美团月付、花呗及两类锁定资金；金额和未知解锁日期留空。“LGB基金”只作为用户提供的名称，不推断真实基金代码。

每一笔基金或不同解锁批次可以单独建账户，填写平台、当前估值、解锁日期和备注。已知资产、欠款、净资产分别汇总；金额未知的账户不计入总额，并明确显示缺失数量。锁定账户到期后标为“待赎回”，不自动当作现金到账，也不自动读取金融平台余额或行情。

- `微信零钱现在有1000元，支付宝余额有2000元，美团月付还欠300元`：初始化或校准当前余额，不新增收入支出。
- `用微信零钱买CoCo奶茶20`：记消费并减少微信零钱。
- `用美团月付买午餐35`：记消费并增加月付欠款。
- `从支付宝余额还美团月付100元`：资产和欠款各减少100元，不重复计消费。
- `新建支付宝7天理财第二批，今天从支付宝余额投进去500元，锁定7天`：创建零余额账户后转入资金，保留解锁日期，不计作消费。
- `LGB基金现在市值880元`：校准估值，不虚构投资收益。
- `我的净资产和锁定资金有多少`：查询资金分布。

Agent只在用户明确说明付款或收款账户时关联账户；未指定的普通收支仍能入账，但不改变任何账户余额。账户转账、投资购买、赎回和还款需要明确两端账户，否则询问。退款默认退回原付款账户，可以明确指定不同到账账户。修改或撤销关联交易会重新计算余额；余额校准及账户修改保留审计记录。已有交易的账户不能改变类型。

初始提示词在 `script/src/ai.ts`，集中定义上述分类、月付负债、转账和锁定规则。模型调用将当前文字、最近20轮双方对话、最近60笔账目和资金账户概况发送到用户配置的模型服务。

## 图片识别与图表

飞书支持私聊图片消息；网页总览文字框右侧的图片按钮支持PNG/JPEG/WebP，最大8MB。图片解码校验、去除元数据并按比例压缩后，通过现有模型的Responses图片输入提取文字，保持金额、正负号和日期，模糊部分标明。飞书需要额外开通应用身份 `im:resource`（上传资源）及 `im:message:readonly`（下载消息中的图片）；如后台提示有待发布修改，再发布应用版本。当前两项权限均已开通，正式机器人图片发送、下载和识字回执均已实际验证，详见 [VALIDATION.md](VALIDATION.md)。

发图默认只提取文字，**不修改账本**。核对后回复 `把这张图片记到账本` 或 `记进去`，机器人提出拟执行方案；回复 `确认` 才执行。同一图片的已确认导入标记永久保存，拒绝再次导入。重新发送的另一张图片仍需自行核对是否与已有账目重复。图片里的文字是数据，不能改变系统规则。

聊天发送 `给我本月账单图片`、`本月支出饼图`、`资金分布图`，即可按真实数据库绘制PNG并加入飞书发送队列。网页“账单”中也可选类型、绘制、下载PNG或发送飞书。图表绘制不调用模型生图；网页生成不消耗模型额度，聊天只用模型识别请求类型与日期。

账单与分类图按选定日期汇总，退款按实际到账日期抵减；跨期退款导致的负值分类仅列明细，不放入饼图。资金图是生成时快照，正值资产形成饼图，负债、负值余额和未知金额分开列明细，未知不当作零余额。所有金额来自整数分汇总。图表快照保存在数据库，PNG丢失可重绘。

中文绘图字体在Mac使用系统Arial Unicode，Linux建议安装Noto Sans CJK；可通过 `CHART_FONT_PATH` 指向中文字体。读图遵循 [OpenAI Docs图片输入格式](https://developers.openai.com/api/docs/guides/images-vision)，实际用户配置的第三方模型接口已单独联调。

## 物品清单

网页左侧“物品清单”保存手机、Mac、耳机、手表等物品的名称、分类、购入价、购买日、停用日和备注，支持编辑、归档与恢复。它是物品登记，不重复记一笔支出，不把历史购入价自动算入现金净资产。

例如 `我的手机叫iPhone 13，2021年9月30日买的，买时3000元，加入物品清单`；然后询问 `iPhone 13用了多久，平均每天多少钱`。程序计算北京日历日期之间的天数，平均每日成本为购入价÷已用天数；当天购买按1天，停用后不继续摊薄，缺价格或日期显示待补全。物品同名时应编辑原记录或用不同名称区分。

## 贷款与借款

网页左侧“贷款与借款”按助学贷款、月付、亲友借款、其他贷款分类，自动包含已有抖音月付、美团月付、花呗等负债账户。贷款资料与负债账户共用同一余额，资金账户、净资产和借款池不会重复相加。

可填写尚欠本金、债权人、合同开始还款日、月还总额、每月还款日、到期日、年利率、贴息截止日和备注。助学贷款没有合同日期时显示待补全；“大四、之后读研三年”只存备注，不自动推断银行政策或还款时间。尚欠汇总中长期贷款按已录入本金，月付按已录入未还余额；利率仅作资料记录，不自行累加尚未确认的利息。

- `我有助学贷款，当前欠24000元，大四，之后读研三年，开始还款日期不知道`：保存欠款及备注。
- `今年这笔助学贷款新增12000元，今天已发生，只累计本金`：增加本金，未指定到账账户时不改其他现金账户。
- `同学借款还欠500元`：创建亲友借款；对象名称不明确时补问。
- `从支付宝余额还助学贷款本金100元，利息5元`：本金减少欠款，利息计入支出。
- `助学贷款2029年10月31日应还本金450元、利息50元`：保存一条合同分期，不自动扣款。

网页支持录入分期、编辑计划、关联部分或全额还款、查看新增本金及还款记录。本月分期待还和计划逾期额仅根据已录入分期计算；普通还款未指定分期时减少贷款余额但不自动猜分期归属。撤销关联本金或利息记录会恢复相应分期待还额。已关联借还记录不能直接编辑，需撤销后重新记录，保证分期一致。

固定月付预览需要开始还款日、月还总额和还款日，展示未来最多6个月，31日遇短月取月末；该预览不代表银行账单或自动摊还计划，不推算利息。系统只记录，不执行真实金融交易。

## 连续对话与确认

飞书私聊会带上同一用户最近20轮已完成交流（包括机器人的实际回复），网页文字记账使用独立会话。账户余额、平台、备注等事实直接读数据库，重启后仍保留；不要求模型自行记忆所有历史。已经入账的历史只用于理解，不应再次执行。用户可以接着说 `累计收益作为京东金融的备注吧`、`可以的，就这样`，无需每次重复原文。

明确提出的待确认操作以结构化方案保存，24小时内可回复 `可以，就这样` 执行或 `取消这个方案` 拒绝。确认不依赖模型再次猜动作，同一消息或方案不能重复执行。等待期间账本或账户有改动时，旧方案失效，需要重新核对。缺少金额、账户或对象的追问继续由带上下文的模型理解，不将猜测写到账本。

平台下多个持仓分别记录，不额外创建重复计资产的父账户。例如京东金融的“灵活、稳健、进阶”各自保存余额和平台；总体累计收益可以作为相关账户备注，不再改变已经是当前市值的余额。

## 主动记账提醒

默认北京时间每日20:00检查；当天没有未撤销的消费、收入或退款时，私聊已绑定用户一次。仅转账、建账户、校准余额或查询不算当天收支。网页“设置 / 记账提醒”可关闭或修改时间。

回复 `今天没有收支` 或 `今天不用提醒` 会记录当天豁免，不新增零金额账目，也不影响明天。排队中的记账消息会先处理；失败消息存在时，提醒也提示核对运行状态。发送前再次检查当天收支，有记录则撤销尚未发送的提醒。

提醒有效窗口为设定时间后1小时，窗口内重新上线可提醒，过期和过去日期不补催。日期去重保存于SQLite，重启不会重复提醒。定时检查不调用模型，使用现有飞书发送队列重试；Mac需在线运行。

## README与操作记录

`reports/README.md` 和 `reports/CHANGELOG.md` 随功能或规则变化更新，并由Git保存；它们是项目说明，不用来存聊天记忆或个人账目。

实际运行目录 `data/operations/YYYY-MM-DD/README.md` 每分钟检查并在内容有变化时自动刷新，记录当天账目新增/修改/撤销、账户操作和消息处理回执。跨日后保留上一日记录，文件权限600，不进入Git。原始记录始终是SQLite及其审计表；这些README只是便于阅读的副本，不能代替数据库备份，也不表示全部历史都已传给模型。

## 定期账单

北京时间每日21:30、周日21:30、每月1日09:00。日报和周报标注统计截止时间，月报覆盖完整上月。21:30后的交易可通过查询或网页手动生成账单查看，不会改写已发送报告。

账单同时附带生成时的已知资产、欠款、净资产和锁定金额。资金概况是生成时的快照，不代表补发账单所覆盖周期末的历史估值。

绑定用户后启用定期账单。遗漏周期在后台恢复后补发，最多回补最近31天；补发日报/周报按当时已入账的完整日期范围统计并标注。已生成账单和待发送队列保存在SQLite中，发送使用稳定UUID降低重试造成的重复。

## Mac后台运行

```sh
npm run service:install
npm run service:stop
npm run service:uninstall
```

安装后登录自动启动，异常退出重启。运行脚本通过 `caffeinate -s` 在接通电源时阻止自动睡眠，允许锁屏和屏幕熄灭；不修改系统原有电源设置。普通笔记本合盖、主动睡眠、关机、断网或电池模式下不保证在线。

macOS 后台进程无法直接访问 Documents 中的项目，所以安装脚本将构建产物和依赖部署到 `~/Library/Application Support/RecordMoney`，仍使用 `data`、`logs`、`script`、`reports` 四目录。实际账本与备份在该目录的 `data`，日志在 `logs/stdout.log`、`logs/stderr.log`。源码始终保留在项目目录中进行 Git 管理。

项目 `data/runtime-location.txt` 记录部署位置，手动启动、备份和恢复会使用同一实际账本；测试可通过 `LEDGER_DATA_DIR` 指定隔离目录。再次安装会同步代码、文档和项目配置，保留实际数据库。服务在用户登录期间运行，退出登录后不保证运行。更新代码后先 `npm run build`，再 `npm run service:install`。先停止手动启动的进程，避免端口冲突。

飞书断线后自动重连；已经收到的消息和待发送任务会持久保存。离线期间平台是否补投消息不作保证，未见记账回执的消息应核对后补发。重发同一事件按消息ID去重；用户重新发送的不同消息是新请求，不会仅因金额相同而去重。

## 备份与恢复

后台每日生成一致SQLite备份，保存最近30份。v0.2同时将原图和图表PNG复制到备份旁的同名 `.sqlite.files` 目录；独立拷贝备份时应同时携带该目录。恢复时同步附件并调整本机路径，旧版纯数据库备份仍可恢复账本及提取文字。网页支持立即备份：

```sh
npm run backup
npm run service:stop
npm run restore -- /完整路径/备份.sqlite
npm run service:install
```

恢复前自动备份当前账本；服务仍在线时拒绝恢复。备份在同一台Mac上，只防误操作和数据库损坏，不防整机故障，重要账本需另外备份实际运行目录中的 `data`。
