# 配置模型服务

可以用便宜的多模态模型，不限定品牌。服务必须支持 **Responses API、图片输入和JSON对象输出**；只有Chat Completions接口的服务暂不能用。

在网页“设置 → 模型服务”填写：

| 字段 | 填什么 |
| --- | --- |
| 服务地址 | API基础地址，例如 `https://example.com/v1`，不加 `/responses` |
| API Key | 模型服务提供的密钥 |
| 模型名称 | 服务商给出的模型标识 |
| 推理强度 | 不确定时选“关闭”，模型支持时再调整 |

点击“测试连接”，通过文字与图片测试后保存。测试使用虚构收据，不写入账本，会消耗少量API额度。

更换模型不清除本地对话、账本或机器人绑定。API Key留空保留原密钥；换服务地址时填新密钥。保存后下一次调用生效。

模型负责读文字、看图片、理解上下文；金额计算和绘图由程序完成。基本连接测试通过后，再用非敏感样例检查：奶茶支出、红包收入、关联退款、多笔截图，以及缺日期和疑似重复时是否主动询问。

调用模型会发送近期对话、相关账目和所上传图片，请使用自己信任的服务。图片核对完成后才确认入账。
