# 模型配置

网页“设置 → 模型服务”选模式：

- **固定格式**：不用模型，不填URL或Key。命令见[使用说明](README.md)。
- **固定格式 + AI**：固定命令优先由程序处理，其他文字交给模型。读图按实际能力启用。

| 配置 | 填什么 |
| --- | --- |
| 接口类型 | 供应商支持的Responses或Chat Completions |
| Base URL | 基础地址，一般以`/v1`结尾 |
| API Key、模型名称 | 供应商提供的值 |
| 推理强度 | 日常记账选“关闭”；已有配置升级后保留 |
| 思考参数 | 仅Chat接口：按供应商文档选`reasoning_effort`或`enable_thinking` |

“测试连接”使用虚构20元收据，分别显示文字、结构化输出和图片能力。状态为“已验证 / 不支持 / 未验证”；一次通过不等于所有账单都能识别正确。文字和JSON通过即可保存，图片失败不阻止文字记账。

网络、密钥或平台图片权限错误会分别提示，不算模型“不支持读图”。发图失败会保留原消息，可在运行状态重试；未启用AI时请发文字。三种账单图由程序生成，随时可用。

更换服务、模型或模式不清除本地账本、对话、图片草稿或待确认方案。API Key留空保留原值，换服务域名时填新密钥；下一次调用生效。切换后新服务能力需重新验证。

金额、统计和绘图由程序计算，不需要昂贵模型；低价候选见[项目首页](../README.md)。模型调用只带近期对话、相关账目和待确认信息，不开启联网或代码执行，不自动换模型。图片排除顶部汇总，逐行核对日期、账户和重复记录，确认才入账。

使用自己信任的模型服务。未知退款对象或贷款还款日期应追问，仍需核对合同。实测结果见[模型验收](MODEL_EVALUATION.md)。
